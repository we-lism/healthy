# 건강참조

병력 기반 일일 건강관리 웹앱(PWA). 안드로이드 크롬 기준.

## 구성
- `index.html` 화면
- `app.js` 로그인·기록·위험도 판정·알림
- `kb.js` 의학 참조자료 DB (하드코딩, 출처 59개, 조사일 2026-11-07)
- `advice.js` 오늘의 맞춤 조언 (현재상태·다음 식사·내일 식단·운동·마음·심장·뇌·통풍)
- `sw.js` 오프라인 실행
- `manifest.webmanifest`, `icons/` 홈화면 아이콘(이름: 건강참조)

## 깃허브 배포 (GitHub Pages)
1. 이 폴더 파일 전체를 저장소 루트에 올리기
2. Settings > Pages > Branch: main / root > Save
3. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 접속

## 휴대폰 아이콘 만들기
1. 안드로이드 크롬으로 위 주소 열기
2. 우측 상단 점 3개 > "홈 화면에 추가" 또는 "앱 설치"
3. 홈화면에 "건강참조" 아이콘 생성

## 규칙
- 기록은 휴대폰 안(localStorage)에만 저장. 1기기 1명.
- 관리자: 아이디 `admin`, 최초 비밀번호 없이 접속 → 비밀번호 설정 강제
- 로그인 후 로그아웃 전까지 자동 로그인
- 알림: 설정 > 알림 등록 (캘린더 매일 반복 6회)

## 참조자료 갱신
`kb.js`의 `SOURCES`, `CONDITIONS`, `FOOD` 수정 후 `KB_VERSION` 날짜 변경.

※ 진료를 대체하지 않습니다. 약 용량 변경은 주치의와 상의.
